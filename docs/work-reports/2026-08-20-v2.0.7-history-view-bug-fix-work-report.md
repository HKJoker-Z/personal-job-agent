# v2.0.7 History View Bug Fix Work Report

## Root cause

History 的 View 事件和 `GET /api/history/{id}` 详情 API 均可用，但详情状态只在最多
50 行的 History 表格末尾追加另一套独立结果 UI。点击后页面既不切换视图也不定位到
详情，因此当前视口看起来没有反应；独立模板也已与 Analyze 完成后的结果展示分叉。

## Fix

- View 请求成功后从列表切换到详情视图，并提供 `Back to History` 返回入口。
- 将已保存的 History detail 映射为展示所需的只读结果形状，复用
  `AnalysisResult`；未调用 `/api/analyze`，也未触发 DeepSeek。
- 保留 History 元数据、人工决策展示和决策更新回调。
- 对旧记录缺失的 RAG、列表、评分、ATS、workflow、cover letter 等可选字段继续使用
  现有安全 fallback。
- 未修改后端 API、History persistence、Analysis、DeepSeek、RAG 或安全扫描行为。
