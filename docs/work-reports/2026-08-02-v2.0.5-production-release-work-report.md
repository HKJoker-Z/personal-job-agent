## 11. Risks and known limitations

- The npm production dependency audit reports two high findings for the React
  Router RSC-mode advisory. This client-only Vite application does not enable
  React Server Components, framework actions, or server routing, so the
  advisory is non-applicable to the deployed execution path. It remains a
  recorded dependency-audit limitation pending a non-breaking upstream fix.
- During the four-request production evidence window, the Provider path had one
  accepted response, one bounded call failure, and two bounded output
  rejections. Existing deterministic analysis fallback contained all three
  non-success outcomes and all four public requests completed. These are
  non-Java Provider-containment observations, not Java failures.
- The four Java-authoritative production requests are bounded rollout evidence,
  not an SLA, load test, capacity result, reliability estimate, or
  performance-improvement claim.
- Java normalization remains deliberately narrow and stateless. FastAPI
  continues to own public APIs, security, idempotency, Project Knowledge,
  Provider work, scoring, History, and monitoring.
