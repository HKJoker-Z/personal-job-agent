# v2.1.0 Applications 工作报告

## Branch

- `feature/v2.1.0-applications`，基于最新 `origin/main` (`fb3a449`) 创建。
- 未合并到 `main`，未创建 Release 或 tag。

## 修改内容

- 复用现有 `applications` 表，新增实际投递所需的公司、职位、JD、Resume 快照和来源 Analysis 字段。
- Analysis 结果页底部新增 `Applied` 按钮；成功后展示明确状态并禁用按钮，同步点击锁与来源 Analysis 唯一约束共同防止重复记录。
- Applied 只新增 Application；原 Analysis 继续保留在 History。
- 手动新增要求 Company Name 和 Job Title，JD 与 Resume 可选；Applied Time 统一由后端生成。

## 数据库 migration

- 新增 Alembic revision `20260820_08`（down revision `20260730_07`）。
- `applications.job_id` 改为可空，以支持不恢复旧 Job 工作流的独立投递记录。
- 新增 `company_name`、`job_title`、`job_description`、`resume_snapshot`、`source_analysis_id`，以及来源 Analysis 的索引和用户级唯一约束。

## API

- `GET /api/applications`：按 Applied Time 倒序返回当前用户的实际投递记录。
- `GET /api/applications/{application_id}`：返回完整 Application 信息。
- `POST /api/applications`：手动新增 Application。
- `POST /api/applications/from-analysis`：从当前 Analysis 创建 Application，并保存当次 Resume 文本快照。
- 旧的编辑、删除、状态流转等 Application API 继续由 retirement boundary 阻止。

## 前端变化

- 主导航新增 `Applications`。
- 新增 Application 列表、完整详情和手动新增表单。
- Analysis 结果页新增 Applied 操作及成功、失败、处理中状态。
- 前后端默认版本标识更新为 `2.1.0`。
