## 4. Release scope and exclusions

The release records the completed private, stateless Java normalization-only
integration: FastAPI-to-Java private networking, `local`/deterministic
`shadow`/authoritative `java` modes, execution-fingerprint and completed-replay
compatibility, pre-Provider execution binding, authoritative second security
scan, and safe `fallback_local` containment.

Phase IVD-B supplied four Java-authoritative production requests with 4/4 Java
success, Request ID match, second-scan acceptance, pre-Provider binding, and
Java execution source; failure/fallback/duplicate side effects/Java-caused
public failure were all zero. The existing Provider path separately contained
one bounded call failure and two bounded output rejections. Those are recorded
as non-Java Provider-containment observations, not Java failures.

Explicit exclusions are database schema/API-contract changes, a migration,
Java source/runtime/image changes, Java policy/dictionary changes, public port
or network changes, provider changes, Java persistence, a performance or SLA
claim, and any reactivation of retired product workflows.
