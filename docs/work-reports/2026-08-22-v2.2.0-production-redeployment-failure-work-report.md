- 隔离 production test account 的 Public HTTPS Login 成功：request ID `v220-production-20260822-login`，Backend HTTP 200。
- Resume create 成功：request ID `v220-production-20260822-resume-create`，Backend HTTP 201，95.413 ms；Resume version create 也成功：request ID `v220-production-20260822-resume-version`，Backend HTTP 201，31.884 ms。
- 下一步 Resume finalize 的 Public HTTPS 连接失败，client 收到 `OpenSSL SSL_connect: SSL_ERROR_SYSCALL`，response body 为 0 bytes；预定 request ID 为 `v220-production-20260822-resume-finalize`，请求未到达 Backend，因此 Backend/Java 没有该 ID，Java duration 与 Backend timeout point 均为 N/A。
- 失败时间窗口：2026-08-22 10:09:25–10:09:54 UTC。Frontend/Edge 的 production 配置关闭 access log；该窗口的 bounded error logs 为空，没有 reset、broken pipe、premature close 或 timeout 记录，因此无法从现有证据确定 TLS connection close owner。
- 因 Public HTTPS hard gate 失败，未继续 production Analyze 或 Applications acceptance，也未将 v2.2.0 判定为生产发布成功。
